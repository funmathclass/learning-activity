# LEARNING ACTIVITY — Frontend

Aplikasi kehadiran guru & karyawan, cover lesson, jadwal piket, jadwal term, dan rekap.
Frontend statis (GitHub Pages) + backend Google Apps Script (REST API JSON).

- `index.html` — kerangka aplikasi (SPA)
- `css/style.css` — sistem desain (terang/gelap, responsif)
- `js/config.js` — **isi `GAS_URL` dan `GOOGLE_CLIENT_ID` sebelum push**
- `js/api.js` — fetch ke Apps Script (POST `text/plain`)
- `js/auth.js` — login "Sign in with Google"
- `js/app.js` — seluruh halaman & logika aplikasi

Panduan lengkap: `PANDUAN-INSTALASI.md`.
